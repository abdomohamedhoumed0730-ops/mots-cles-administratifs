# Guide 07 · Vérifier le lien public

**Objectif.** S'assurer que le lien fonctionne pour quelqu'un qui n'est pas vous, sur un autre appareil.

## Étapes

1. Ouvrez une **fenêtre de navigation privée** (Ctrl + Maj + N dans Chrome ou Firefox).
2. Collez l'adresse publique et appuyez sur Entrée.
3. Faites ces quatre tests, dans l'ordre :
   - **Test 1** : la page s'affiche, avec le bandeau vert.
   - **Test 2** : choisissez la note N14 dans le menu, cliquez sur **Extraire les mots-clés**. Un tableau et une mesure apparaissent.
   - **Test 3** : passez à **Coller un texte**, collez une phrase de votre choix, cliquez. Les mots-clés apparaissent, sans mesure.
   - **Test 4** : cliquez sur **Télécharger le tableau (CSV)**. Un fichier se télécharge.
4. Ouvrez l'adresse sur votre téléphone, sur un réseau différent si possible.

## Vérification
Les quatre tests réussissent, sur deux appareils au moins.

## En cas de problème
- **« This app has gone to sleep »** : cliquez sur le bouton de réveil, puis attendez.
- **Une erreur rouge à l'écran** : ouvrez les journaux (menu en bas à droite, **Manage app**), relevez l'erreur, et suivez la section « En cas de problème » du guide 06.
