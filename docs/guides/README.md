# Guides pas à pas

Un guide par étape, dans l'ordre. Chaque guide dit ce qu'il faut faire, la commande ou le clic exact, et comment vérifier que c'est réussi.

| # | Guide | Durée | Quand |
|---|---|---|---|
| 01 | Installer le projet sur votre ordinateur | 15 min | Maintenant |
| 02 | Lancer l'application en local | 5 min | Maintenant |
| 03 | Vérifier que tout passe avant publication | 10 min | Avant le dépôt |
| 04 | Créer le dépôt GitHub | 5 min | Avant le déploiement |
| 05 | Envoyer le code sur GitHub | 10 min | Avant le déploiement |
| 06 | Déployer sur Streamlit Community Cloud | 15 min | Avant le jury |
| 07 | Vérifier le lien public | 5 min | Juste après le déploiement |
| 08 | Annoter les 20 notes (évaluation humaine) | 1 h | Avant le dépôt |
| 09 | Préparer la démonstration de 2 à 4 minutes | 30 min | Avant le jury |
| 10 | Plan de secours le jour J | 10 min | Avant le jury |
| 11 | Liste finale avant la soutenance | 10 min | La veille |

**Règle d'or.** Un guide n'est terminé que si la vérification qui le clôt est réussie. Si une étape échoue, ne passez pas à la suivante : notez le message d'erreur et relisez la section « En cas de problème ».
