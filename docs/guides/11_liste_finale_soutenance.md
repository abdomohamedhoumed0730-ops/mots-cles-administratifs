# Guide 11 · Liste finale avant la soutenance

À cocher la veille, dans l'ordre. Chaque case doit être vraie.

## Projet
- [ ] `make tout` se termine sans erreur sur votre ordinateur.
- [ ] Le dépôt GitHub contient la dernière version (guide 05).
- [ ] L'application publique répond (guide 07 : quatre tests réussis).
- [ ] L'application locale démarre (guide 02).

## Rapport et diapositives
- [ ] Le rapport PDF fait 6 pages, en noir et blanc, sans page de garde ni image décorative.
- [ ] Les noms du binôme figurent sur la première page du rapport.
- [ ] Le lien public figure dans le rapport et sur la diapositive de démonstration.
- [ ] Les diapositives sont au nombre de 8 à 10 (exigence du sujet).
- [ ] Le rapport mentionne le résultat de l'évaluation humaine (guide 08), ou dit clairement qu'elle n'a pas été réalisée.

## Démonstration
- [ ] Le déroulé dure entre 2 et 4 minutes, sur deux répétitions (guide 09).
- [ ] La note de secours est prête sur une clé USB (guide 10).

## Oral
- [ ] Chaque membre du binôme peut expliquer les quatre méthodes, le protocole de test gelé et les erreurs relevées.
- [ ] Réponse prête à : « Pourquoi la méthode 2c n'est-elle pas retenue ? » (elle a été conçue sur le jeu d'évaluation, le test gelé ne la confirme pas).
- [ ] Réponse prête à : « Pourquoi un corpus synthétique ? » (pas de données réelles disponibles, données personnelles en jeu).

## Le jour même
- [ ] Ordinateur chargé, chargeur dans le sac.
- [ ] Application lancée une fois avant d'entrer dans la salle.
- [ ] Clé USB et téléphone avec le lien public.
